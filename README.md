# E-Portfolio \| นายวิชญะ ถาวรผล

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) สำหรับรวบรวมข้อมูลแนะนำตัว ความสนใจ
ทักษะ ผลงาน และกิจกรรมของ **นายวิชญะ ถาวรผล (ภูมิ)** นักเรียนชั้นมัธยมศึกษาปีที่ 6
โรงเรียนธัญรัตน์

เว็บไซต์ออกแบบด้วยธีม **สีขาว--น้ำตาล--ครีม** ในสไตล์ Elegant Vintage
เน้นความเรียบหรู อ่านง่าย และรองรับการใช้งานบนหน้าจอหลายขนาด

## เทคโนโลยีที่ใช้

-   HTML --- จัดโครงสร้างหน้าเว็บไซต์
-   CSS --- ตกแต่งหน้าตาเว็บไซต์และรองรับหน้าจอมือถือ
-   JavaScript --- ควบคุมเมนูบนมือถือ ตัวกรองผลงาน และเอฟเฟกต์การแสดงเนื้อหา
-   Google Fonts --- ใช้ฟอนต์ Prompt สำหรับภาษาไทย

## ส่วนประกอบของเว็บไซต์

1.  **หน้าแรก (Home)** --- แนะนำแฟ้มสะสมผลงาน
2.  **แนะนำตัว (About Me)** --- ข้อมูลส่วนตัว ความสนใจ และทักษะ
3.  **ผลงาน (My Works)** --- หมวดวาดภาพ งานปั้น และงานสร้างสรรค์
    พร้อมตัวกรองหมวดหมู่
4.  **กิจกรรมและประสบการณ์ (Activities)** ---
    พื้นที่รวบรวมประสบการณ์และการเรียนรู้
5.  **ติดต่อ (Contact)** --- ลิงก์ไปยัง GitHub

## วิธีเปิดใช้งานในเครื่อง

1.  ดาวน์โหลดหรือคัดลอกไฟล์ `index.html` ลงในโฟลเดอร์โปรเจกต์
2.  เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ เช่น Google Chrome
3.  หากต้องการแก้ไขเนื้อหา ให้เปิด `index.html` ด้วยโปรแกรมแก้ไขโค้ด
    แล้วแก้ไขข้อความในส่วนที่ต้องการ

> เว็บไซต์เวอร์ชันนี้รวม HTML, CSS และ JavaScript ไว้ในไฟล์ `index.html`
> เพียงไฟล์เดียว

## วิธีเผยแพร่ด้วย GitHub Pages

1.  สร้าง Repository ใหม่บน GitHub
2.  อัปโหลดไฟล์ `index.html` และ `README.md` ไปไว้ใน Repository
3.  เข้าเมนู **Settings** ของ Repository
4.  เลือก **Pages**
5.  ในส่วน **Build and deployment** เลือก **Deploy from a branch**
6.  เลือก Branch ที่ต้องการ (เช่น `main`) และเลือกโฟลเดอร์ `/ (root)`
7.  กด **Save** แล้วรอ GitHub Pages เผยแพร่เว็บไซต์

เมื่อเผยแพร่สำเร็จ GitHub จะแสดง URL สำหรับเข้าใช้งานเว็บไซต์ไว้ในหน้า Pages

## หมายเหตุ

เนื้อหาในส่วนผลงานและกิจกรรมบางรายการเป็นข้อความตัวอย่างเพื่อแสดงรูปแบบการจัดวาง
ยังไม่ใช่การยืนยันว่าเป็นผลงานหรือกิจกรรมที่เจ้าของเว็บไซต์เคยเข้าร่วมจริง
ควรเปลี่ยนเป็นข้อมูลและภาพผลงานจริงก่อนเผยแพร่
